## 💡 Pro Tips

### Mobile Number Format:
```
✅ Correct:   9876543210
✅ Correct:   8765432109
✅ Correct:   7654321098
✅ Correct:   6543210987

❌ Wrong:     5876543210  (starts with 5)
❌ Wrong:     98765       (less than 10)
❌ Wrong:     98765432109 (more than 10)
```

### Password Tips:
```
✅ Minimum 6 characters
✅ Can include: letters, numbers, symbols
✅ Case-sensitive
✅ Example: admin123, mypass@456, DCS2024
```

### Remember Me:
```
✅ Saves your mobile number
✅ Auto-fills on next login
✅ Doesn't save password (secure!)
✅ Convenient for regular use
```
